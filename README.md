# 🍔 Howdy! Restaurant Website

A multi-page **static front-end website** for **Howdy!** — a famous charcoal-grilled gourmet burger chain in Pakistan. Built entirely with **HTML and CSS**, the site replicates a real food chain's online presence with a fully navigable interface including a home page, menu, deals, login/signup, cart, and payment pages.

---

## 🌐 Pages

| Page | File | Description |
|---|---|---|
| **Home** | `home_page.html` | Landing page with image slider, About Us section, and footer |
| **Menu** | `menu_page.html` | Food menu with categories (Appetizers, Burgers, etc.), item cards with prices |
| **Deals** | `deal_page.html` | Active combo deals with prices and upcoming deals notice |
| **Login** | `login_page.html` | Side-by-side Login and Sign Up forms |
| **Cart** | `cart_page.html` | Cart items grid with quantity, individual totals, and overall total |
| **Payment** | `payment_page.html` | Billing address form + payment options (Cash on Delivery / Credit Card) |

---

## ✨ Features

- **Responsive Navbar** with logo and cart icon — links across all pages
- **Auto Image Slider** on the home page (CSS-only, 3 slides)
- **About Us** section with brand story and description
- **Menu cards** — item image, name, description, price (PKR), and Add to Cart button
- **Deals section** — combo deal cards with details and pricing
- **Login & Sign Up** forms side by side with Remember Me checkbox
- **Cart page** — grid layout showing items, quantities, and computed totals
- **Payment page** — billing address fields + Cash on Delivery / Credit Card radio options
- **Footer** on every page — contact number, email, and social media icons (Facebook, Instagram, Twitter)
- **Custom favicon** (Howdy logo) in the browser tab

---

## 🛠️ Tech Stack

- **HTML5** — semantic page structure and forms
- **CSS3** — layout (flexbox/grid), styling, image slider, responsive design

> No JavaScript, no frameworks — pure HTML & CSS.

## 🚀 Getting Started

No installation needed. Just clone and open in a browser:

```bash

cd Website-of-Restaurant
```

Then open `home_page.html` in any web browser.
